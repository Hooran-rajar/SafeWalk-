SAFEWALK - START HERE

1) Extract this ZIP.
2) Open the extracted safewalk_flutter_project folder in VS Code.
3) In Terminal, generate platform folders and get dependencies:
     flutter create .
     flutter pub get
   Keep the existing lib/main.dart and other source files if prompted.
4) Run preview:
     flutter run -d chrome
5) The app opens in Preview mode before Firebase setup.
6) Follow README.md to connect Firebase before using real login/database.
7) Build APK with: flutter build apk --release
8) For web hosting, see the Firebase Hosting section in README.md.

Note: This archive contains the authored Flutter app source. Flutter SDK,
Android SDK, generated platform folders/build output, and your personal
Firebase configuration are not included. Firebase config is generated by
running `flutterfire configure`.
